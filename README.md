
# BMI Calculator | Abdi_J

A simple BMI Calculator built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

[Open BMI Calculator](https://abdulhamidjemal.github.io/bmi-calculator-by-abdi/)

## ✨ Features

- Interactive weight slider
- Interactive height slider
- Automatic BMI calculation
- BMI result and category display
- Dark-themed user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub Pages

## 🚀 Run Locally

1. Clone this repository.
2. Open `index.html` in your browser.
